# Bowed-Adventure

A Gutiar Hero based game based for the violin or viola

## About the Game

The game was supposed to be an arcade version of Gutiar Hero where users will play and get a random piece to play. The pieces I have choosen are not insanly hard which adds to that arcade feel. This random selection will intensive players to come back.

### controls

for the fingers in the keybord order. These fingers reperesent what fingers you press down on the violin.

a, s, d, and f.

Notes will go over a blank spot outside of the fingers. Do not press any buttons as those are for playing an open string on the violin.

## Languages and Libarys

I went with C# for the language for several reasons

- I wanted to learn a static typed language

- I wanted to learn a pure oop language

- The structure is better to scale code than a language like Python

- I needed a language that was decently fast

- C# is known for games

The Language was inbetween Java and C# and C# had a more applealing game libarys and syntax.

I went with Raylib for several reasons

- Easy to learn

- Cheatsheet made it easy for me to look up functions when I needed them

- If I want to learn another language, Raylib has bindings in a lot of languages

- Raylib-cs seemed like the most simple libary or framework in C#
